# Basen.uz — ответы на вопросы о проекте

Данные на 08.10.2026. Пункты с пометкой **[заполнить]** знает только владелец: их нельзя
проверить по коду и данным.

## Техническая часть

1. **Nuxt 3** (Vue 3, TypeScript, Tailwind CSS). Сайт генерируется как статика
   (`nuxt generate`) и размещён на своём сервере **Hetzner**, раздаёт nginx. Деплой
   автоматический: GitHub Actions после каждого пуша в `main`.
2. Разработчик один — владелец (Mirjalol Mirxomitov). Код пишется вместе с ИИ (Claude
   Code). Проект начат 29.06.2026, с тех пор 368 коммитов.
3. В **JSON-файлах** в репозитории: `data/pools.json` (145 бассейнов) и рядом файлы
   регионов, районов, FAQ и гайдов. Базы данных и CMS нет. Слой данных сделан так, чтобы
   потом заменить JSON на API.
4. **Админки нет.** Любое изменение — правка JSON и коммит, после чего сайт
   пересобирается сам.
5. Да, **GitHub**: `github.com/Mirjalol9797/basen-frontend`. Репозиторий
   **публичный**, код можно смотреть без отдельного доступа.
6. Через **ИИ (Claude)**, с ручной проверкой.
   - Интерфейс переведён полностью на ru, uz и en.
   - Названия и адреса бассейнов есть на трёх языках у всех 145.
   - **Описания бассейнов на uz и en есть только у 8 из 145.** У остальных uz и en
     страницы показывают карточку без описания.
7. **Да.** Sitemap собирается модулем `@nuxtjs/sitemap` (индекс `/sitemap_index.xml`)
   для трёх языков. Hreflang и canonical проставляет модуль i18n (`useLocaleHead`) на
   каждой странице. URL-схема: ru без префикса, `/uz/...`, `/en/...`. Пустые регионы и
   районы исключены из sitemap и отдают noindex.

8. Основной поток: владелец собирает данные вручную с **Google Maps, Яндекс Карт и
   Instagram/Telegram** бассейнов, а ИИ оформляет их в JSON и сверяет координаты.
   Обзвон и личные визиты — **[заполнить]**. Первые фото и часть карточек на старте
   взяли с сайта pools.uz скриптом.

   устаревают, пока их не обновят руками.
10. **Не свои.** Скачаны с pools.uz (скриптом) или взяты с Google Maps, из Instagram и

    132 из 145 бассейнов. ⚠️ Прав на эти фото у проекта нет, это юридический риск.
11. Регулярного обновления нет: данные вносятся при добавлении бассейна, правки бывают

12. **Цены есть у 71 из 145** (49%). Ещё у одного вход указан как бесплатный.
